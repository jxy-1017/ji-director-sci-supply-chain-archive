# 通俗类比词典

| 概念 | 类比 |
|---|---|
| 数据Atlas | 大型仓库总盘点 |
| 主键 | 每条记录的唯一身份证 |
| 实体映射 | 把不同数据库中的同一家企业认成同一对象 |
| coverage | 摄像头覆盖范围，没拍到不等于现实中不存在 |
| 真实G | 企业真正开始受到政策影响的年份 |
| CS-DID | 不同对象在不同时间进入政策时的分组比较方法 |
| 全文索引 | 给每份报告建立可检索目录 |
| 主题模型 | 把大量报告按内容放到不同主题书架 |
| 语义残余 | 尚未能归入已解释书架的材料 |
| 路线死亡测试 | 正式施工前检查地基、材料和道路是否齐全 |
